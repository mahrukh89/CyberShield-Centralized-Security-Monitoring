# Lessons Learned

## What Went Well

- Early stakeholder mapping reduced communication gaps.
- Clear acceptance criteria improved testing.
- RAID tracking made dependencies visible.
- Sprint reviews created regular feedback loops.
- Formal change control limited uncontrolled scope growth.

## What Could Improve

- Secure technical access earlier.
- Add more buffer around integration testing.
- Confirm resource availability before sprint commitment.
- Establish KPI reporting earlier.

## Recommendations for Future Projects

1. Perform dependency discovery during initiation.
2. Create a technical-access checklist before implementation.
3. Define UAT criteria during requirements.
4. Maintain a live RAID log.
5. Review schedule variance weekly.
6. Use formal change control for baseline changes.
