# Weekly Project Governance Meeting Notes

## Meeting Purpose

Review delivery progress, milestones, risks, dependencies, decisions and actions.

## Standard Agenda

1. Previous actions
2. Overall project status
3. Milestone progress
4. Sprint progress
5. Risks and issues
6. Dependencies
7. Change requests
8. Decisions required
9. Next-period priorities

## Example Meeting Record

**Meeting:** Weekly Governance Review  
**Attendees:** Project Manager, Sponsor, Security Lead, SOC Representative, IT Operations  
**Status:** Active governance

### Decisions

- Priority log sources remain unchanged.
- Dashboard KPI set approved.
- UAT entry criteria confirmed.
- Documentation must be complete before operational handover.

### Action Items

| Action | Owner | Due | Status |
|---|---|---|---|
| Confirm remaining source access | IT Ops | W4 | Open |
| Validate detection test cases | Security Lead | W6 | In Progress |
| Schedule UAT | PM | W8 | Open |
| Finalize training material | PM | W9 | Open |

### PM Practice Demonstrated

Meeting notes capture **decisions, owners and due dates**, rather than simply recording discussion.
