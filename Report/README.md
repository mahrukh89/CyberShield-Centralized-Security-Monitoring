\# 📸 Visual Evidence \& Project Dashboards



This directory contains high-impact, visual proof of execution for the \*\*Wazuh SIEM Enterprise Implementation\*\* project. 



Rather than overwhelming recruiters with low-value static screenshots of basic text tables, this repository uses a \*\*hybrid evidence model\*\*:

1\. \*\*Interactive Tool UI \& Data Visualizations\*\* are captured here as high-resolution screenshots (`01`–`05`).

2\. \*\*Quantitative \& Governance Control Files\*\* are hosted as editable, live spreadsheets (`.xlsx`) and structured Markdown (`.md`) across their respective repository folders.



\---



\## 📑 Core Evidence Gallery



\### `01-work-breakdown-structure.png`

\* \*\*Artifact Type:\*\* Scope Architecture Diagram (WBS)

\* \*\*Tool Used:\*\* Draw.io / Flowchart Engine

\* \*\*Purpose:\*\* Demonstrates visual decomposition of the project down to Level 2 technical work packages (Wazuh Manager installation, Sysmon log collection, rule tuning, and SOC playbooks).



\---



\### `02-gantt-chart.png`

\* \*\*Artifact Type:\*\* Project Timeline \& Schedule

\* \*\*Tool Used:\*\* Jira Timeline / Gantt View

\* \*\*Purpose:\*\* Displays phased sprint execution, milestone markers, task sequencing, and critical-path dependencies across the project lifecycle.



\---



\### `03-jira-board.png`

\* \*\*Artifact Type:\*\* Active Agile Sprint Kanban Workspace

\* \*\*Tool Used:\*\* Jira Software

\* \*\*Purpose:\*\* Highlights real-time task movement across workflow stages (`Backlog` → `To Do` → `In Progress` → `Review/Testing` → `Done`) with assigned epics and clear ownership.



\---



\### `04-project-dashboard.png`

\* \*\*Artifact Type:\*\* Executive KPI Dashboard

\* \*\*Tool Used:\*\* Jira Dashboards / Performance Gadgets

\* \*\*Purpose:\*\* Provides at-a-glance delivery metrics, including sprint velocity, log-source onboarding progress, open defect tracking, and scope completion rates.



\---



\### `05-risk-matrix.png`

\* \*\*Artifact Type:\*\* 3x3 Risk Exposure Heatmap

\* \*\*Tool Used:\*\* Excel / Google Sheets Visual Matrix

\* \*\*Purpose:\*\* Aggregates and visually maps active project risks across \*\*Probability (1–5)\*\* vs. \*\*Impact (1–5)\*\* to drive proactive executive mitigation strategies.
