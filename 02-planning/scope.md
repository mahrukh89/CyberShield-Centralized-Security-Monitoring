# Scope Management

## Scope Statement

The project will coordinate the planning and delivery of a centralized security monitoring capability, including priority telemetry onboarding, detection requirements, workflows, reporting, validation, training and operational handover.

## In Scope

- Project governance
- Requirements gathering
- Current-state assessment
- Priority log-source planning/onboarding
- Detection use cases
- Alert triage workflow
- Incident escalation
- Dashboard requirements
- Testing
- UAT
- Documentation
- Training
- Operational handover

## Out of Scope

- Penetration testing
- Red-team exercises
- Enterprise-wide security transformation
- Replacement of existing endpoint products
- Major network redesign
- Long-term SOC staffing
- Unapproved production changes

## Scope Boundaries

Any request that materially affects approved deliverables, timeline, cost, resources or risk must enter change control.

## Scope Acceptance

The Sponsor accepts the project scope when the defined in-scope deliverables and exclusions are agreed and baseline documentation is complete.
